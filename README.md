# 🏦 طراح هوشمند محصولات بانکی ایران

موتور طراحی محصولات تسهیلاتی برای بانک‌ها و مؤسسات اعتباری، منطبق بر **عقود بانکداری بدون ربا** و **مصوبات شورای پول و اعتبار**. سامانه از طریق گفتگوی محاوره‌ای نیاز مدیر محصول را استخراج می‌کند، سپس یک محصول کامل و قابل پیاده‌سازی طراحی کرده و چهار تحلیل الزامی را به‌صورت **عدد + نمودار + تفسیر** ارائه می‌دهد:

| تحلیل | خروجی |
|---|---|
| ⚖️ انطباق مقرراتی | ۱۲ کنترل: اعتبار عقد، سقف نرخ، شفافیت نرخ مؤثر، کارمزد، ماده ۱۴، وجه التزام، ALM و … |
| 💧 ریسک نقدینگی (ALM) | شکاف نقدینگی در ۵ افق، ۷ سناریو (پایه / تاخیر ۳۰–۶۰–۹۰ روز / NPL ۵–۱۰–۱۵٪) |
| 📈 سودآوری | واترفال درآمد ⟵ هزینه تامین ⟵ EL ⟵ عملیاتی ⟵ حاشیه خالص، IRR، RAROC، سربه‌سر، حساسیت ۵×۵ |
| ⭐ جذابیت مشتری | امتیاز ۰–۱۰۰ از ۵ معیار وزنی و مقایسه با ۳ رقیب فرضی |

خروجی نهایی: **مستند ۱۴ بخشی «مشخصات محصول»**، ۱۷ نمودار با پروتکل JSON استاندارد، گیج سلامت محصول از ۱۰۰ و فلوچارت فرایند عملیاتی.

---

## ✨ قابلیت‌ها

- **۱۱ عقد تسهیلاتی**: مشارکت مدنی و حقوقی، فروش اقساطی، اجاره به شرط تملیک، سلف، جعاله، استصناع، قرض‌الحسنه، خرید دین، مزارعه/مساقات، مضاربه — هر یک با مبنای قانونی، سقف نرخ، بازه مدت، ریسک‌های خاص و راهکار پوشش
- **ماتریس انطباق نیاز ⟵ عقد** با توجیه ۳ دلیل فنی و هشدار در صورت انتخاب عقد ناسازگار
- **۶ ساختار بازپرداخت**: اقساط مساوی (annuity)، خطی/سُرد، تسویه یکجا، صعودی، نزولی، پرداخت سود و اصل در سررسید — با دوره تنفس و ریتم ماهانه/فصلی
- **محاسبه هم‌زمان نرخ اسمی و نرخ مؤثر (IRR)**؛ هرگز نرخ خارج از سقف مصوب طراحی نمی‌شود
- **مدل ALM واقعی**: هزینه تامین روی مانده کاهنده، سررسید و نرخ تمدید سپرده‌ها، هسته پایدار، خط اعتباری پشتیبان
- **ریسک اعتباری**: `EL = PD × LGD × EAD` با PD بخش بازار، تنزیل وثیقه و پوشش وثیقه‌ای خالص در سناریو بحرانی
- **گفتگوی محاوره‌ای فارسی** با پارس مبلغ (میلیارد/میلیون)، مدت، درصد و کلیدواژه‌های عقد/وثیقه/بخش؛ فرض‌های هوشمند با برچسب «فرض — قابل تغییر»
- **اصلاح تعاملی آبشاری**: هر تغییر، اثرش بر قسط، نرخ مؤثر، حاشیه، کف نقدینگی، جذابیت و سلامت را پیش/پس گزارش می‌کند
- **تنظیمات سازمانی بانک**: هزینه تامین واقعی، سابقه NPL، هزینه عملیاتی، کفایت سرمایه، سقف نرخ مصوب، نرخ سپرده‌ها و تاریخ اعتبار دانش
- **گنجینه طراحی‌ها** در PostgreSQL با صورت‌جلسه گفتگو، چرخه وضعیت (پیش‌نویس ⟵ بررسی ⟵ تصویب ⟵ بایگانی) و مقایسه سبد
- خروجی JSON نمودارها (کپی/دانلود)، چاپ گزارش و دانشنامه عقود

- **Next.js 16** (App Router, Server Components, Route Handlers)

<div dir="ltr">


## 🔌 API

### `POST /api/preview`
محاسبه کامل محصول بدون ذخیره.

<div dir="ltr">

```json
{
  "spec": {
    "needCode": "vehicle",
    "segment": "retail",
    "baseAmount": 500000000,
    "tenorMonths": 36,
    "repaymentMode": "annuity",
    "collateralCode": "check",
    "collateralCoverage": 130,
    "nominalRate": 23,
    "fundingCode": "matched_long",
    "currency": "IRT"
  }
}
```

</div>

پاسخ: `{ report: ProductReport }` شامل `contract`, `financial`, `liquidity`, `profitability`, `attractiveness`, `health`, `compliance`, `documentation[14]`, `visualizations[17]`, `quality`.

### پروتکل بصری (بخش ۸)
هر نمودار با این ساختار خروجی داده می‌شود و مستقیماً در فرانت‌اند رندر می‌گردد:

<div dir="ltr">

```json
{
  "id": "profit-waterfall",
  "type": "waterfall | bar | line | radar | heatmap | gauge | table | comparison | cards",
  "title": "...",
  "subtitle": "...",
  "data": { "categories": [], "series": [], "items": [], "matrix": [], "value": 0 },
  "insight": "تفسیر سه‌جمله‌ای"
}
```

</div>

## ⚙️ نرخ‌های پیش‌فرض

| عقد | نرخ |
|---|---|
| مشارکت مدنی / استصناع / جعاله | ۲۳٪ |
| مشارکت حقوقی | ۲۳٪ تا ۲۸٪ |
| فروش اقساطی / اجاره به شرط تملیک | ۲۳٪ (+ مابه‌التفاوت ۴ تا ۸٪ در قالب مجاز) |
| سلف / خرید دین | ۲۰٪ |
| قرض‌الحسنه | ۰٪ + کارمزد حداکثر ۲٪ |
| سپرده کوتاه‌مدت / ۱ / ۲ / ۳ ساله | ۱۲٫۵٪ / ۱۷٫۵٪ / ۱۸٪ / ۲۰٪ |

> ⚠️ این مقادیر پیش‌فرض هستند و در **تنظیمات سازمانی** قابل به‌روزرسانی با مصوبه جدید شورای پول و اعتبار می‌باشند.
